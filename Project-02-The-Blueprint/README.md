# Project 02: The Blueprint (Wireframing)

**DecodeLabs UI/UX Design Internship | Week 2**

## Project Overview

The Blueprint is the second project of my DecodeLabs UI/UX Design Internship. In this project, I created a low-fidelity homepage wireframe for STRIDE, a conceptual sneaker e-commerce store.

The main focus was on creating a clean layout with clear information hierarchy and a logical user flow.

## The Challenge

An e-commerce brand was losing customers because its homepage layout was cluttered and confusing. The task was to create a simple homepage structure that makes it easier for users to explore products and understand the available actions.

## What I Created

- **Hero Section:** A benefit-driven headline with one primary call-to-action.
- **Product Categories:** Five visual categories to make product discovery easier.
- **Best Sellers:** Four featured products with clear product information.
- **Button Hierarchy:** Solid black for the primary action and outlined styles for secondary actions.
- **Trust Elements:** Shipping and returns information, customer reviews, and a closing CTA.
- **Stock Status:** Availability information displayed on product cards.

## Design Approach

The wireframe uses only black, white, and grey to keep the focus on structure, content placement, user flow, and hierarchy rather than visual styling.

## Key Learning

Structure comes before style. A clear wireframe helps create a strong foundation for the final visual design and improves the overall user experience.
