# Project 3: The Visual Identity 🌿

**UI/UX Design Internship | DecodeLabs | Batch 2026**

## About the Project

Project 3, titled **The Visual Identity**, focuses on transforming wireframes into a high-fidelity mobile app design.

The challenge was to create a modern and premium visual identity for a conceptual organic food delivery service called **Fieldly**.

The goal was to communicate three important values through visual design:

- Trust
- Health
- Speed

## Project Overview

**Brand Name:** Fieldly  
**Tagline:** Farm-fresh, at your door.  
**Project Type:** Mobile App UI Design  
**Category:** Organic Food Delivery  
**Design Tool:** Figma

## Design Deliverables

### 1. Style Tile

Created a visual identity system for Fieldly, including:

- Professional color palette
- Typography selection
- Playfair Display for headlines
- Montserrat for body text and UI elements
- Type scale and accessibility contrast considerations

### 2. Splash Screen

Designed a welcoming introduction screen featuring:

- Fieldly brand identity and wordmark
- Farm-fresh tagline
- Natural organic produce imagery
- Get Started call-to-action button

### 3. Product List Screen

Designed a product browsing experience featuring:

- Search bar
- Product category filters
- Rainy Day Comforts personalized suggestion
- Two-column product grid
- Product prices and calorie information
- Quick-add buttons
- Bottom navigation

### 4. Product Details Screen

Designed a detailed product information screen featuring:

- High-quality product imagery
- USDA Organic and Non-GMO badges
- Product name and pricing
- Farm-to-table harvesting information
- Product description
- Quantity selector
- Weekly subscription option
- Add to Cart button

## Visual Design System

### Color Palette

| Color | HEX Code |
|---|---|
| Leaf Green | `#2F7D32` |
| Fresh Lime | `#8BC34A` |
| Soft Sage | `#F1F7E8` |
| White | `#FFFFFF` |
| Earthy Brown | `#6B4A3A` |
| Harvest Gold | `#E8B93C` |
| Deep Ink | `#1F2A1C` |
| Berry Red | `#B3261E` |

### Typography

- **Playfair Display:** Headlines and brand identity.
- **Montserrat:** Body text, buttons, prices and UI elements.

### Design Principles

- 8-point spacing grid
- Consistent alignment and spacing
- Clear visual hierarchy
- Accessible color contrast
- Natural daylight product imagery
- Consistent UI components
