# Project 4: The Living Prototype

**Week 4 | DecodeLabs UI/UX Design Internship, Batch 2026**

## The challenge

The Fieldly screens were ready, but stakeholders could not yet "feel" how the app works. They wanted to see transitions, button clicks, and the overall flow before the design goes to developers. The goal was to turn static screens into a clickable prototype that looks and acts like a real app.

## Live prototype

- **Figma prototype (click through it):** [Open the Fieldly prototype](https://www.figma.com/proto/lbCpsaIUXJghFlvtDbFraI/UIUX_INTERN-Decodelabs?node-id=15-2&t=c0qReGD22FeJEoQN-1&scaling=scale-down&content-scaling=fixed&page-id=0%3A1)

> Start at the Splash screen and tap **Get Started**.

## What I created

- Connected the Fieldly screens with prototyping links, so the app can be explored from the Splash screen to the Order Placed screen.
- A home screen with category tabs (All, Vegetables, Fruits, Organic, Local), each shown as its own screen.
- A "Rainy Day Comforts" screen, reached from the banner on the home screen.
- A bottom navigation connecting Home, Explore, Favorites, Order, and Profile.
- A cart and order flow that ends on an Order Placed confirmation screen.
- Smooth screen transitions and button interactions to make the flow feel natural.

## Happy path

Splash > Home > Product Details > Add to Cart > Order > Order Placed

## Key lesson

We do not just design screens, we design behavior. Transitions, feedback and a clear flow are what make a design feel real.
